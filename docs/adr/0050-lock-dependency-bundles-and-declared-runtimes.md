# Lock dependency bundles and declared runtimes

Exact dependency identity uses a canonical Bundle Manifest containing normalized relative paths, byte sizes, per-file SHA-256, declared executable bits, and a manifest digest; symlinks and special files are rejected. Package, Contract, Provider, DRC, and Generator sub-bundles are independently locked and verified before launch, and a manifest inside a sub-bundle never embeds that same bundle digest. Runtime Locks identify a sealed runtime distribution/loader/library/module closure plus platform ABI, invocation profile, environment profile, search-path policy, and prohibited-network declaration; bare PATH lookup is forbidden. V1 promises verifiable replay under identical design, bundles, runtime closure/profile, platform ABI class, and tool input, not cross-platform bit-for-bit output equality.
