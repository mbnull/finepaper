# Lock Default Engine as an installable exact Bundle

Every System Design pins exactly one independently installable immutable Default Engine Bundle; `bundleManifestDigest` is its sole implementation identity, while ID/version are metadata and `engineCompatibilityVersion` only classifies explicit migrations. The Engine exposes a versioned C-compatible `engineHostContractVersion` over Gate 0 canonical models. Host-owned topology side effects are independently versioned by `hostSideEffectContractVersion`. Missing, revoked, corrupt, digest-mismatched, Host/platform-incompatible Engines open degraded inspect mode and never fall back to the current application Engine. Explicit Engine migration reuses the digest-confirmed candidate transaction to atomically update dependency lock, Derived State, Host side effects, and provenance; Undo uses the saved inverse transaction without executing an Engine.
