# Use one Pending Topology Group and an independent Draft Overlay

V1 permits at most one uncommitted topology transaction. Topology-driving edits coalesce inside that Group and become authoritative only when final intent, the selected Authority Patch, Application Domain/Attachment side effects, tombstones, Host ID allocations, and derivation metadata commit atomically as one formal history entry. While the Group is open, topology-bound commands are disabled and ordinary edits are only locally undoable Draft Overlay proposals; they do not mutate ProjectDesign, enter formal history, affect reconciliation, or permit formal Save, and are revalidated for independent submission after materialization. Failure preserves the Group for retry or discard without changing authoritative design.
