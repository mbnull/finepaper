# Provide common NoC design capabilities in the Default Engine

The product supplies an exact immutable installable schema-driven Default NoC Engine Bundle for V1 Mesh topology, global/Interface/Domain configuration, Router/Slot/Link lifecycle, single-Slot Interface attachment, total-exclusive-connected Domains, schema-declared Package entities/relations, Domain/diagnostic presentation, Patch execution, projection, structural DRC, and workflow hosting. It interacts through the versioned Engine Host Contract and never falls back across bundle digests. The three shipped NoC Packages use these capabilities declaratively without Package Providers; broader scopes and generic overlay/configuration DSLs are reserved, and Extension Providers exist only for behavior the common model cannot express.
