# Create the NoC through a focused wizard

New System Designs are created through a guided flow covering design identity, Mesh-wide configuration, initial required Domains, and a final review. NoC Interfaces are added and attached after entering the main workbench; later global configuration changes use a dedicated panel with explicit Apply and optional debounced automatic updating. One editing gesture or debounce window produces one typed user command and at most one reconciliation request; Escape cancels an uncommitted draft, and a failed Apply preserves the draft with its error.
