# Define protocols through versioned Contract Packages

Protocol identities, roles, capabilities, and matching rules are supplied by independently versioned Contract Packages rather than hardcoded in the core or redefined by each NoC Package. The first product release ships official contracts for AXI5, ACE, and CHI, while the core remains protocol-neutral. A future externally visible proprietary coherent protocol is added as another public Contract Package without changing the core matching model.
