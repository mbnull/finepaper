# Use a three-pane NoC design workbench

After the creation wizard, the main workbench uses a stable three-pane layout: design navigation on the left, the Mesh canvas in the center, and a contextual Inspector on the right, with Problems and tool output in a collapsible bottom area. The layout prioritizes repeated design iteration rather than forcing users through a persistent step-by-step flow or hiding core object management in drawers.
