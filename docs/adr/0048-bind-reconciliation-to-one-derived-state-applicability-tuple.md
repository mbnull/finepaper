# Bind reconciliation to one Derived State applicability tuple

Reconcile receives only canonical normalized topology input, canonical current Derived State, required dependency locks, and declared capabilities. The Authority Patch embeds the complete applicability object: exact Group/generation, topology-input and base Derived-State revisions/digests, base authoritative-design digest, selected Authority and Package/reconcile dependency digests, exact Default Engine lock/digest, Engine Host contract, and Host side-effect contract; Session revision is provenance only and Engine compatibility version is migration classification only. Derived State includes Router/Link/Slot and all ownership=`engine` Package objects/properties relevant to generation or later reconciliation. Its revision is monotonic through materialize, Undo, and Redo, and Authority-owned derived data cannot itself be topology-driving.
