# Select Access Slots with an anchored picker after dropping on a Router

Dropping a NoC Interface on a Router opens a compact Router-anchored Slot picker when multiple legal Access Slots exist; a single legal Slot attaches immediately. Disabled Slots remain visible with reasons, Escape cancels, cancellation leaves a newly created Interface unattached and preserves the original attachment during reattachment, and a confirmed selection submits one undoable typed Application command that compiles to an internal Patch.
