# Make V1 Access Slots single-occupancy design resources

An Access Slot is a stable Router attachment resource whose selection affects generator input and observable external connection position; it is not a Network Interface implementation instance or a canvas coordinate. V1 Slots have capacity one, declare allowed Contract/role and stable display position, and may be grouped into shared NI implementations only by generation. Dropping on a Router accepts a unique legal Slot or opens the anchored picker when several are legal.
